EARNFORFUTURE — STARTER WEBSITE
================================

WHAT IS INCLUDED
- Responsive homepage
- Three original starter articles
- About, Contact, Privacy, and Disclaimer pages
- CSS design, mobile navigation, and favicon
- No paid assets, login, database, analytics, or ad scripts

PREVIEW ON YOUR COMPUTER
1. Extract this ZIP to a folder.
2. Open index.html in Chrome, Edge, or Firefox.
3. Click the links and test the menu on a narrow browser window.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a NEW PUBLIC repository named exactly:
   your-github-username.github.io
   (replace with your actual GitHub username)
3. Upload the contents of this folder into the repository root.
   Important: upload index.html, styles.css, script.js, README.txt,
   robots.txt, the assets folder, and the articles folder—not just the ZIP.
4. In the repository, open Settings > Pages.
5. Under build/deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment, then visit:
   https://your-github-username.github.io/
   Replace the placeholder with your actual username. First publish may take
   a few minutes. If you use a different repository name, the URL differs.

BEFORE YOU APPLY FOR ADS
- Replace the contact page's placeholder note with a real contact method.
- Review the Privacy and Disclaimer pages so they match your actual practices.
- Publish more original, genuinely useful articles; do not copy other sites.
- Check current Google AdSense eligibility, country availability, site policies,
  tax/payment requirements, and age requirements directly with Google.
- Add an ad script only after acceptance and only as instructed by the ad provider.
- Approval and income are not guaranteed. A website being online does not mean
  it is approved for ads or will earn money.

IMPORTANT NOTES
- This is a static informational blog, not an earning/rewards platform.
- There is no login, payment, comment system, newsletter, or contact form.
- No advertisements or analytics are active in this starter version.
- GitHub Pages is intended for static sites and has usage restrictions; review
  its current terms before using it for any commercial activity.
- Free hosting gives you a platform subdomain; a custom .com domain usually costs money.
- Do not add fake income claims, fake testimonials, or copied content.
